TREE DATA structure

A tree data structure is a non-linear, hierarchical structure used to represent data in a parent–child relationship.
Key Points:
Nodes: The fundamental units of the tree that store data.
Root: The topmost node in the tree (has no parent).
Edges: Connections between nodes that represent relationships.
Child: A node directly connected below another node.
Parent: A node that has one or more child nodes.
Leaf: A node with no children.
Subtree: A tree formed by any node and its descendants.
